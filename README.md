## Use a solution

Open the matching LeetCode problem, select C++, and paste that file's `Solution` class and includes into the editor. Each file is a separate submission with its own `Solution` class; compile or submit them individually.

LeetCode supplies the test harness and, for Add Two Numbers, the `ListNode` definition shown in the file's comment. To run that solution locally, supply that definition and a separate test harness. These files do not include an application entry point.
